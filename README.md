# Hotel VMS Demo — Intelligent Video Surveillance

Interactive demo (no physical cameras) of a **Milestone XProtect + AI analytics** workflow for a Valencia hotel with 30 Safire cameras.

## Start

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Features

- **Introduction dashboard** with project overview and hotel/CCTV photos (Unsplash)
- **ES / EN language switch** in the top bar (saved in localStorage)
- Operations panel, live view, watchlists, rules, alerts, search, GDPR
- Auto event simulator + **Run hotel scenario** button

## Interview tip (~6 min)

1. Open **Introduction** — show scope, photos, phases  
2. Switch **ES ↔ EN**  
3. Go to **Operations** / click **Run hotel scenario**  
4. Show Alerts, Search, Rules, GDPR  

## Note

This is a **workflow / UX simulation**, not real Milestone or BriefCam.
